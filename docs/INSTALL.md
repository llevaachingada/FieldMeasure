# Install Field Measure on a Surface

Print this for the shop. It takes 2 minutes and needs Wi-Fi **once**. After that the app works with
no signal.

**App link:** https://llevaachingada.github.io/FieldMeasure/
(If the shop has made its own copy, use that link instead. Ask whoever looks after the app.)

## 1. Install

1. Open **Microsoft Edge** and go to the app link.
2. Tap the **Install** icon at the right end of the address bar, then **Install**.
   No icon? Tap **…** → **More tools** → **Apps** → **Install Field Measure**.
3. The app opens in its own window with no address bar. From now on, open it from the **Start
   menu** or the taskbar, not from Edge.

## 2. First run

1. **Which hand do you write with?** Tap Right or Left. The tool rail moves to the other side so
   your hand doesn't cover it.
2. **Where should your projects live?** Tap **Use Documents\FieldMeasure**. When asked about
   folder access, choose **Allow on every visit**.

## 3. Check it works offline

1. Turn on **airplane mode**.
2. Close the app and open it again from the Start menu.
3. It opens. Turn airplane mode back off.

If it doesn't open offline, open it once with Wi-Fi on, wait 30 seconds, and try again.

## Using it

Tap **Help** at the top of any screen. Each project is a folder in `Documents\FieldMeasure`. To
share one, drag the folder or its PDF into Dropbox, or attach the PDF to an email.

## If something goes wrong

- **No Install option:** make sure it's Edge and the exact link. It may already be installed:
  check the Start menu.
- **"This browser can't save to folders":** use Microsoft Edge.
- **Home says "Folder permission expired":** tap **Re-authorize**, then **Allow on every visit**.
- **The first-run questions came back and the projects are gone:** the app was opened from a
  different link. Pick the same folder again; every project is still there.
- **"Update ready" banner:** tap **Reload** when you're between photos. Your work is saved first.
