# Appendix — Scaffold file reference (slice 0.1)

> Source: `docs/preflight-handoff-v0.3-hardened.md` **§2.2** (stack, pins, CSP, notices), **§12**
> (repo layout), **§13/0.1**; `docs/implementation-plan.md` **slice 0.1**; `docs/DECISIONS.md`
> **D14** (versions), **D24** (origin); **§21.1** (origin), **§21.6** (TypeScript), **§19.2**
> (service worker).
>
> This is a reference for what each slice-0.1 file **MUST** contain. Everything the specs already
> fix is stated verbatim. Anything the specs do **not** fix is marked
> `— verify at scaffold (C1)` and must be resolved (and recorded in `docs/DECISIONS.md`) before
> the slice gate is signed off. Where a version or license cannot be confirmed from the docs it is
> marked the same way; do not guess.
>
> **Pin rule (§2.2):** exact versions, no `^`/`~`, committed lockfile, `npm ci` in CI. The single
> documented exception is TypeScript (see below).

---

## `package.json`

**Must contain** (implementation plan slice 0.1, build-order step 1):

- `"type": "module"`.
- `"private": true` — `— verify at scaffold (C1)` (not stated; a local-only PWA should not be
  publishable by accident).
- `"name"` / `"version"` — `— verify at scaffold (C1)` (not stated).
- `"engines"` — Node **24 LTS** per **D14** (the version boundary is the toolchain's, not the
  app's) `— verify at scaffold (C1)` for the exact `engines` string.
- Real scripts: `dev`, `build`, `preview`, `test`, `e2e`, `typecheck` (named in build-order
  step 1). Bodies below are grounded in the CI command list (§13/0.1 step 8) and §21.1's ports.
- **Exact pins** for all runtime deps and all listed dev deps.

**Runtime deps — exact pins (D14 / §2.2).** The runtime list is closed (§2.2); adding one requires
a spec change first.

```json
"dependencies": {
  "@cantoo/pdf-lib": "2.11.1",
  "fflate": "0.8.3",
  "idb-keyval": "6.3.0",
  "immer": "11.1.18",
  "konva": "10.6.0",
  "lucide-react": "1.47.0",
  "perfect-freehand": "1.2.3",
  "react": "19.3.0",
  "react-dom": "19.3.0",
  "zod": "4.6.5",
  "zustand": "5.0.15"
}
```

**Dev deps.** Pins marked `<pin …>` are **not** fixed by the docs (session 4 added the deps, not
their versions) — resolve with `npm view <pkg> version` at C1 and record them.

```json
"devDependencies": {
  "@playwright/test": "1.63.0",
  "@testing-library/react": "<pin — verify at scaffold (C1)>",
  "@testing-library/user-event": "<pin — verify at scaffold (C1)>",
  "@vitejs/plugin-react": "6.1.1",
  "jsdom": "<pin — verify at scaffold (C1)>",
  "typescript": "^5",
  "vite": "8.3.0",
  "vite-plugin-pwa": "1.3.0",
  "vitest": "5.0.1"
}
```

- `@types/react` / `@types/react-dom` — required for `strict` TSX. Not named in the docs.
  `— verify at scaffold (C1)`; pin exact versions if added (they are type-only, not a runtime
  dep, so they do not touch the closed list, but §2.2's pin rule still applies).
- **`typescript`: `^5` is a placeholder, not a pin.** Spec **§21.6** pins TypeScript to **5.x for
  v1** and supersedes D14's `7.0.2`. The exact 5.x patch is resolved at scaffold with
  `npm view typescript@5 version` (**checkpoint C1**) and then written as an **exact** pin. Do not
  hardcode a 5.x patch that has not been verified. (`^5` is the one allowed non-exact range;
  replace it with the resolved exact version before the slice gate.)

**Scripts (grounded):**

```json
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview",
  "test": "vitest run",
  "e2e": "playwright test",
  "typecheck": "tsc --noEmit"
}
```

- `build` runs `vite build`; CI typechecks **separately** with `npx tsc --noEmit` (§13/0.1 step
  8). Whether `build` should also typecheck `— verify at scaffold (C1)`.
- `preview` must serve on port **4173** for Playwright/§21.1 `— verify at scaffold (C1)` (Vitest/
  Vite default; Vite preview defaults to 4173).

## `package-lock.json`

- Commit **as-is**; do **not** hand-edit (slice 0.1 file list). Generated by `npm install`.
- `npm ci` installs from it in CI (§2.2, §13/0.1).
- If a pin fails to resolve, check the lockfile against `node_modules`; **do not silently widen a
  pin** (slice 0.1 rollback note) — widening a pin is a DECISIONS change.

## `vite.config.ts`

**Must contain** (§13/0.1 build-order steps 2, 6, 13; §19.2; §21.1):

- `@vitejs/plugin-react` and `vite-plugin-pwa`.
- `base` from **`process.env.FM_BASE ?? '/'`** (§21.1 part 3) — the build is origin-agnostic; a
  host move is a rebuild, not a code edit.
- `vite-plugin-pwa`:
  - `registerType: 'prompt'` — **never `autoUpdate`** (§19.2, D25).
  - `manifest`:
    - `name` / `short_name` — `— verify at scaffold (C1)` (not stated; expected "Field Measure").
    - `icons` — from `public/icons/*`.
    - `display: 'standalone'` (build-order step 2).
    - `start_url: '/FieldMeasure/'` — the exact string slice 0.0 wrote into DECISIONS
      (§21.1; default). **Copy verbatim; do not invent it** (build-order step 13). With the
      origin-agnostic `base`, the actual value is the `base` path.
    - `scope: '/FieldMeasure/'` — same rule (§21.1).
    - `theme_color` / `background_color` — `— verify at scaffold (C1)` (not stated; UI spec §3.3
      owns the token values).
  - `workbox` precache `globPatterns` covering the **app shell, both fonts (`.woff2`), and icons
    (`.png`/`.svg`)** (§13/0.1 step 12). A font not matched by the glob is a **silent no-op**.
  - **No `runtimeCaching` entry** that could capture `blob:` URLs or user files (§13/0.1 step 2;
    §2.2 "never cache user photos").
- **CSP** (§2.2, verbatim — meta tag in `index.html` or a dev/middleware header):

  ```
  default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' blob: data:; font-src 'self'; connect-src 'self' blob:; media-src 'self' blob:; worker-src 'self' blob:; frame-ancestors 'none'; base-uri 'none'; form-action 'none'
  ```

  `blob:` is required only for camera/import preview and canvas export.
- The Vite worker convention must build: `new Worker(new URL('./decodeWorker.ts',
  import.meta.url), { type: 'module' })` (§13/0.1, `src/media/decodeWorker.ts`).

## `tsconfig.json`

**Must contain** (§13/0.1 build-order step 3; §21.6):

- `"strict": true` (mandatory).
- `"moduleResolution": "bundler"`.
- `"jsx": "react-jsx"`.
- Path alias `@/* → src/*` (the plan's literal alias; this is how `src/*` imports resolve).
- `"noEmit": true` (CI runs `npx tsc --noEmit`).
- `"lib"`, `"target"`, `"module"`, `"types"`, `"include"` — `— verify at scaffold (C1)` (not
  stated). `target`/`lib` must let React 19 typecheck under `strict` with TS 5.x.
- `npx tsc --noEmit` must pass under **TS 5.x** with `strict: true` (§21.6). TypeScript 7 is a
  post-beta task.

## `vitest.config.ts`

**Must contain** (§13/0.1 build-order step 9) — **two projects in one config**:

- `node` project (default): `environment: 'node'`, `include: ['tests/**/*.test.ts']` —
  pure domain tests (units/geometry/snapping/schema).
- `jsdom` project: `environment: 'jsdom'`, `include: ['tests/**/*.test.tsx']`,
  `setupFiles: ['tests/setup.ts']` — component tests.
- Convention: `.test.ts` = pure/node; `.test.tsx` = component/jsdom. Nothing else to remember.
- `tests/setup.ts` — jsdom setup. **`@testing-library/jest-dom`-style matchers are not added**;
  use plain assertions to keep the dep list small.

---

## `playwright.config.ts`

**Must contain** (§13/0.1 build-order step 10):

- `testDir: 'tests/e2e'`.
- **Chromium only** (the target is Edge/Chromium).
- `webServer: { command: 'npm run preview', port: <preview port>, reuseExistingServer:
  !process.env.CI }` — the preview port is **4173** per §21.1 `— verify at scaffold (C1)`.
- One smoke spec `tests/e2e/smoke.spec.ts` (app loads, title is right) so the harness is proven
  green **before** a later slice depends on it.
- This harness serves three later gates: 1.2's kill-switch, 1.3's zoom-constancy screenshot diff,
  1.9's export invariance.

## `.github/workflows/ci.yml`

**Must contain** (§13/0.1 build-order step 8; §2.2):

1. `npm ci` (against the committed lockfile).
2. `npx tsc --noEmit`.
3. `npx vitest run` (must run **both** projects).
4. `npm run build`.
5. `npx playwright test` — after `npx playwright install --with-deps chromium` (Chromium only).
6. A step asserting **`THIRD-PARTY-NOTICES.md` exists** (§2.2; the CI-checked requirement).
- Trigger, Node version, cache strategy, job/step names — `— verify at scaffold (C1)` (not
  stated). Node must be **24 LTS** (D14).

## `src/main.tsx` / `src/App.tsx` / `src/ui/strings.ts`

- `src/main.tsx` — minimal React 19 root that mounts `App` (build-order step 4). No
  domain-specific code.
- `src/App.tsx` — a placeholder screen (nothing domain-specific).
- `src/ui/strings.ts` — **empty** string table: `export const STRINGS = {} as const`
  (build-order step 4). All user-visible text lives here from now on (§12). The inventory to fill
  it is `docs/appendix-strings.md`; its unresolved gaps are
  `docs/appendix-strings-gaps.md` (PROPOSED).
- `src/data/originGuard.ts` — slice 0.1 ships the origin guard (§21.1 part 3): stores the
  origin+base the profile's data was created under; on `'changed'` shows a **blocking** screen
  `«This app moved to a new address»` with `Pick my projects folder`. **Never silently fall
  through to first-run.**

## `public/icons/*` and fonts

- `public/icons/*` — **original placeholder** PNG + SVG art (never third-party) (build-order
  step 5; §12). Will be replaced with final art before 2.0.
- `public/fonts/*.woff2` — **Archivo** (UI) and **JetBrains Mono** (numerals), **self-hosted,
  no CDN** (UI spec §3.3; §13/0.1 step 12). Applies `@font-face` with `font-display: swap`.
  - Subset to **Latin + the glyphs the app actually draws** (`′ ″ ° × ≈ ⌫ ✓`).
  - Record the subsetting command in the file header comment so it is reproducible.
  - Workbox `globPatterns` must actually precache `**/*.{woff2,png,svg}`.

## "Done" checklist for the scaffold (slice 0.1 gate)

- [ ] `npm run build` succeeds; `npm run dev` serves in Edge.
- [ ] `«Install app»` works; **after install, reload in airplane mode still opens the app**
      (SW precache). `[Surface]` — log to `docs/HARDWARE-TEST-CHECKLIST.md`; does not block.
- [ ] `THIRD-PARTY-NOTICES.md` exists and names all 11 runtime deps **and both font licenses**.
- [ ] CI green on push (`npm ci` → typecheck → vitest → build (+ Playwright, notices check)).
- [ ] `npx vitest run` runs **both** projects (node + jsdom) and both smoke tests pass.
- [ ] `npx playwright test` passes the smoke spec against `npm run preview`.
- [ ] Both fonts load from `/fonts/` with the network offline after install (text not in a
      fallback face). `[Surface]` — log to the hardware checklist.
- [ ] `decodeWorker.ts` is bundled and instantiable (smoke test constructs it, gets a message back).
- [ ] Manifest `start_url`/`scope` match slice 0.0's DECISIONS entry **exactly**.
- [ ] No `runtimeCaching` rule can capture `blob:`/user files.
