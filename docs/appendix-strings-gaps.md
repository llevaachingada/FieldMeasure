# Appendix — Proposed strings for `appendix-strings.md` gaps

> **STATUS: PROPOSED — NOT APPROVED COPY.**
>
> This file fills the 26 items in the `## Gaps` section of `docs/appendix-strings.md` — places the
> specs say need user-visible text but never provide a verbatim `«…»` string. Every string below is
> a **proposal** from the builder, not spec copy. A human must review and approve the wording before
> any of it ships into `src/ui/strings.ts`.
>
> - It does **not** modify or replace any existing verbatim string in `docs/appendix-strings.md`.
> - Keys follow that file's convention: dot-namespaced camelCase, area-prefixed.
> - Tone is plain and functional (say what the control does), matching the existing strings — no
>   marketing.
> - Gap numbering matches `docs/appendix-strings.md` `## Gaps` items 1–26.
> - Refs use that file's convention: `U §x:line` = `ui-spec-field-measure-v2-hardened.md`;
>   `P §x:line` = `preflight-handoff-v0.3-hardened.md`.
